# Contributing

Thanks for taking the time to contribute!

> [!NOTE]
> `dispatrick/clidle-test` is a test fixture: a clone of
> [`ajeetdsouza/clidle`](https://github.com/ajeetdsouza/clidle) used as a sandbox for
> testing [Dispatch](https://upsun.com). If you want to improve the game itself,
> please contribute to the upstream project instead.

## Reporting issues

Use [GitHub Issues](https://github.com/dispatrick/clidle-test/issues) to report bugs or
suggest features. Please include:

- what you did, what you expected, and what happened instead;
- your OS and Go version (`go version`);
- any relevant logs or terminal output.

## Development setup

You need a Go toolchain matching the version in [`go.mod`](go.mod).

```sh
git clone https://github.com/dispatrick/clidle-test.git
cd clidle-test
go build ./...
```

Run the game locally in your terminal:

```sh
go run .
```

Or start the SSH server and connect to it:

```sh
go run . -serve 127.0.0.1:3000
ssh 127.0.0.1 -p 3000
```

Game data is stored in your XDG data directory by default; set `CLIDLE_DATA_DIR` to
use a different location.

### Database code

The code in [`store/`](store) is generated by [sqlc](https://sqlc.dev) from
[`schema.sql`](schema.sql) and [`query.sql`](query.sql) (see [`sqlc.yaml`](sqlc.yaml)).
Don't edit it by hand. Change the SQL files and regenerate:

```sh
sqlc generate
```

## Making changes

1. Fork the repository (or create a branch if you have write access).
2. Create a descriptively named branch, e.g. `fix-score-display`.
3. Keep commits small and focused, with clear messages explaining *why* the change
   was made.

## Formatting and checks

Before opening a pull request, make sure the code is formatted and passes the basic
checks:

```sh
gofmt -l .     # should print nothing
go vet ./...
go build ./...
```

## Pull requests

- Describe what the change does and why, and link any related issue.
- Keep each pull request focused on a single change.
- Make sure the checks above pass.
- A maintainer will review your pull request and may ask for changes.
